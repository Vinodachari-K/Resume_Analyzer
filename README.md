# Resume_Analyzer
# 🚀 AI Resume Analyzer

An AI-powered web application that analyzes resumes and provides score, skills, and improvement suggestions using **Google Gemini API**.

---

## 🔥 Features
- 📄 Upload Resume (PDF)
- 🤖 AI-based Resume Analysis
- 📊 Score Generation
- 🧠 Skills & Missing Skills Detection
- 💡 Improvement Suggestions

---

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: Node.js + Express.js
- AI API: Gemini API
- File Upload: Multer
- PDF Parsing: pdf-parse
